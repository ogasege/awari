Awari as a download for Windows, macOS and Linux. It is the same app as the website, with every
article, quiz, Castle room, map, timeline event and small picture inside, so it works with no
internet from the first launch. Bigger versions of pictures still load from Wikimedia Commons when
there is a connection.

**Downloads**
- Windows: `Awari-<version>-win-x64.exe` (installer)
- macOS: `Awari-<version>-mac-arm64.dmg` (Apple silicon) or `Awari-<version>-mac-x64.dmg` (Intel)
- Linux: `Awari-<version>-linux-x86_64.AppImage` (make it executable, then run it)

**Not code-signed.** These installers are not signed or notarised, so your system will warn you.
- macOS: drag Awari to Applications, then right-click it and choose Open, then Open again.
- Windows: on the SmartScreen warning, choose More info, then Run anyway.

**Licences.** The code is MIT (see `LICENSE`). The content keeps its own licences: the text is from
Wikipedia and Wiktionary (CC BY-SA 4.0), and each picture keeps its own licence and author from
Wikimedia Commons (public domain, CC0, CC BY or CC BY-SA). The app's Credits screen and the bundled
`CREDITS.md` and `NOTICE` list them.

Built by the `Desktop installers` workflow from this tag. Only the macOS build was opened and tested
by hand; the Windows and Linux builds rely on this workflow passing.
