# Tech

## Stack

- React 19 + TypeScript (strict) + Vite. No UI framework; hand-made
  components and CSS custom properties for tokens.
- A small in-house router (history API) to keep first-load JavaScript
  small. Routes are lazy-loaded with `React.lazy`.
- `d3-geo` for the atlas globe (orthographic projection on SVG), loaded
  only on the Atlas route.
- Fonts self-hosted through `@fontsource` packages (SIL OFL) so they work
  offline: Bricolage Grotesque 800, Figtree, Covered By Your Grace.
- Service worker written by hand (`src/sw/sw.ts`), built to `/sw.js`, with a
  precache list generated at build time. Progress is stored in IndexedDB
  through a small wrapper (`src/lib/store`).
- Content packs are static JSON in `public/packs/`, generated by
  `npm run packs` (Node + `tsx`) from open data and committed, so the app
  builds without network access.
- Quiz service: one AWS Lambda (Node.js 22, TypeScript, AWS SDK v3
  `@aws-sdk/client-bedrock-runtime`, Converse API) in
  `services/quiz-lambda`. The app never depends on it.
- Infrastructure: Terraform in `infra/terraform` (S3, CloudFront with
  origin access control, Lambda function URL behind CloudFront).

## Testing

- Vitest + jsdom + Testing Library for unit and component tests.
- fast-check for property-based tests. Every correctness property listed
  in a spec's `design.md` has a test whose name starts with `Property N:`
  and is tagged with the requirement numbers it covers.
- `fake-indexeddb` for storage tests.
- Playwright (CLI, local only) for screenshots and the airplane-mode check.

## Commands

- `npm run dev` / `npm run build` / `npm run preview`
- `npm run lint` (ESLint flat config + typescript-eslint, zero warnings)
- `npm test` (Vitest run) and `npm run test:props` (property tests only)
- `npm run packs` builds every content pack from one command.
- `npm run check` runs lint, typecheck, tests, credits, rules and bundle
  budget checks: the gate before a task is marked done.

## Budgets and rules

- First load under 300 KB of JavaScript (uncompressed, measured by
  `scripts/check-bundle.ts` from the built `index.html`), before packs.
  Packs load on demand.
- No secrets in the repo. AWS settings come from the environment or
  Terraform variables; nothing is applied without the owner.
- All code is new work. Libraries come from npm under their own licences;
  nothing is copied from other projects.
